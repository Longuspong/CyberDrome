# Porträts für Kacheln

Bilder nur für die kleinen Kopf-Anzeigen (Zwischenstopp, Squad-Kacheln im
Kampf), wenn ein Chassis seinen Kopf nicht als eigenes Teil zeichnet.
Dateiname = ID des Kopf-Teils (`<head_id>.svg`); `UiKit.portrait_texture`
nimmt sie, wenn das Kopf-Teil leer ist.

* `jugg_head.svg` -- Molok. Sein Kopf steckt seit 17. Nov. 2026 im Rumpf
  (Tiefensortierung); das hier ist der Kopf von davor, mit Auspuffen und
  Lockfeuer.
