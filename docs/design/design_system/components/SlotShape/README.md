# SlotShape

Halter-Symbol: die Form zeigt das Gewicht eines Waffenplatzes -- Dreieck leicht, Viereck mittel, Fuenfeck schwer, Kreis Kern.

## Regeln
- Leicht passt nach oben in groessere Halter, schwer nur in schwer.
- Strich 2 in `yellow` neben dem Waffennamen; leerer Halter gestrichelt in `empty-line`.
- Die Form traegt die Bedeutung, nicht die Farbe -- der Name steht immer daneben.

Nachgebaut aus `SlotShape` (`scripts/ui/slot_shape.gd`).
