# Modules

Die 27 Modul-Symbole des Spiels (`assets/modules/<modul-id>.svg`, 64 x 64, transparent). **Eigene Farben** -- die Platzhalter nutzen die Klassenfarben `module-attack`, `module-defense`, `module-tactic` und Akzent `#e8eef6`. Sie liegen immer im ModuleChip (Grund `module-fill`, Rand in der Klassenfarbe) und fuellen 80 % davon; an den Haltern ist der Chip nur ~36 px gross -- kraeftige Linien, wenig Details. Fehlt ein Symbol, zeigt der Chip zwei Buchstaben.
