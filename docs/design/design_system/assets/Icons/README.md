# Icons

Die 82 UI-Symbole des Spiels (`assets/ui_icons/`), 24 x 24, Strich 2, eckige Enden. **Tinte: weiss (`#ffffff`) auf transparent** -- auf hellem Grund unsichtbar. Beim Einsatz einfaerben: im Spiel ueber `modulate`, im Web als Maske (`cd-icon`, Farbe aus `color`). Farben nur aus den Tokens (`yellow` Waehrungen, `cyan` aktive Bedienung, `muted` inaktiv, `good`/`bad` Zustaende).

Gruppen: Pfeile und Chevrons, Waehrungen (`credits`, `coin`, `kit`, `cache`), Werte (`hp`, `shield`, `def`, `speed`, `power`, `range` ...), Schadensarten (`kinetic`, `energy`, `virus`), Zustaende (`stun`, `slow`, `vulnerable`, `lured`, `heal`), Tabs (`tab_*`), Rollen (`role_*`), Modulklassen (`class_*`), Gegnerstufen (`tier_*`), Kampfkarte (`location`, `loot`, `rush` ...).
